# 📚 POO com Java: Herança e Tratamento de Exceções
Repositório dedicado ao estudo aprofundado de Programação Orientada a Objetos (POO), utilizando a linguagem Java. Este projeto consolida os conceitos práticos e teóricos abordados nas aulas das disciplinas de Linguagem de Programação I e II.

## 🎯 Foco Principal do Estudo
Os exemplos de código e a estrutura deste repositório foram desenhados para ilustrar e praticar os seguintes conceitos essenciais:
